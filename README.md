# 🚴 Bike Demand Prediction using Machine Learning

## 📌 Objective

To build a regression model that predicts bike demand based on various factors like weather, season, and time.

---

## 📊 Dataset

* Bike sharing dataset
* Features include:

  * Temperature
  * Weather conditions
  * Season
  * Year
  * Holiday / Working day

---

## 🔍 Key Analysis

* Demand variation across seasons
* Impact of weather conditions
* Year-wise growth in demand
* Correlation analysis

---

## 🤖 Model Used

* Linear Regression

---

## 📈 Key Insights

* Bike demand is highest during clear weather
* Demand increases in year 2019 compared to 2018
* Temperature is the most important factor
* Demand drops during holidays

---

## 🧠 Concepts Used

* Data Cleaning
* Feature Engineering
* Dummy Variables
* Multicollinearity (VIF)
* Model Evaluation

---

## 📊 Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn

---

## 📌 Conclusion

This project demonstrates how machine learning can be used to predict demand and support business decisions.
